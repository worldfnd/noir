---
title: Data Bus
description: The call_data and return_data modifiers are not supported; use plain and pub parameters instead.
---

The data bus is not supported. The `call_data` and `return_data` modifiers still parse, but the
compiler refuses them on every function with the error `call_data(<id>) is not supported` or
`return_data is not supported`.

A program reads its inputs and writes its return as bytes, so the data bus has nothing to group.
Use a plain parameter instead of `call_data`, and `pub` for a public input or return value:

```rust
fn main(x: u32, y: u32, z: [u32; 4]) -> pub u32 {
  let a = z[x];
  a + y
}
```
